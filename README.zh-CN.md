ScreenRecorder 通过 **Windows.Graphics.Capture** 捕获全屏、单个窗口或自定义区域，使用 **Media Foundation 硬件编码器**（H.264/H.265 + AAC）编码，输出紧凑、可直接播放的 MP4。内置时间轴编辑器可对录制进行裁剪、缩放、画面裁切与标注，再导出为 GIF、PNG 贴纸或转码 MP4 —— 没有臃肿的运行时，没有水印，没有遥测。

## ✨ 功能

### 🎥 捕获
- **三种来源** —— 全屏（多显示器感知）、任意应用窗口、精确自定义区域
- **拖拽选区** —— 点「选择区域」在目标显示器的**冻结截图**上弹出置顶蒙层，拖动出矩形：框内完整透出实时桌面，框外整体压暗。选区以虚拟桌面坐标 + 缩略图保存。最小选区 8 px
- **悬浮工具栏** —— 置顶迷你控制条固定在屏幕角落，自动**从录制画面中排除**（`WDA_EXCLUDEFROMCAPTURE`）
- **鼠标捕获** —— 光标包含在画面中；Windows 10 2004+ 上自动隐藏 WGC 的黄色录制边框（`SetIsBorderRequired(false)`）

### 🎬 编码
- **硬件加速** —— Media Foundation H.264 / H.265 (HEVC)；系统无 HEVC 编码器时自动降级 H.264
- **画质档位** —— 从低码率小文件到"蓝光级" ultra 档；也可完全自定义码率
- **VBR / CBR** 码率控制
- **零拷贝 GPU 通路** —— 帧数据全程留在 D3D11 管线，从捕获直通编码器

### 🔊 音频
- **系统声音**（WASAPI loopback）与**麦克风**独立开关，各自音量可调
- **麦克风选择** —— 输入设备下拉列出全部已启用的采集端点（系统默认项标注「默认」），所选设备以 WASAPI 端点 id 持久化
- 双源统一降混为单声道 48 kHz，混音后 AAC 编码封装进同一个 MP4

### ✂️ 时间轴编辑器
- **工程**只引用原始录制 + 编辑数据，从不复制媒体文件；自动保存为录制文件旁的 `<recording>.srec.json`
- **剪辑** —— 在播放头处分割、删除、拖动排序、裁掉首尾，并支持 0.25×–2× 变速
- **缩放** —— 时间段 + 深度（1–6 档 → 1.25×–5×）+ 归一化焦点。实现上采用**裁切**而非缩放绘制，故放大画面仍保持输出分辨率
- **画面裁切** —— 支持 全幅 / 留边 / 居中 80% 预设；与缩放叠加生效（裁切确定基础矩形，缩放在其中取景）
- **标注** —— 文字与箭头，可选颜色、字号、背景与旋转角，各自带独立的起止时间
- **背景** —— 深色 / 浅色 / 无 / 日落 / 海洋 预设，可调留白、圆角与投影
- **缩放建议** —— 编辑器读取光标轨迹，对「快速移动」或「长时间静止」自动给出候选缩放区间；仅作为建议，不会自动应用
- **撤销 / 重做**（100 步）与 1280×720 实时画布预览，支持逐帧定位

### 📤 导出
- **GIF** —— 1280×720，由 Rust 手写的 GIF89a 编码器输出（不依赖任何 crate，也不需要 ffmpeg）：固定 256 色立方调色板、有序抖动、透明色索引、无限循环。8–24 fps；时间轴过长时**降低帧率**而非截断
- **PNG 贴纸** —— 播放头所在帧的合成画面，输出 RGBA，带透明留白、圆角与高斯模糊投影
- **MP4 转码** —— 调用**你 PATH 上已有的 ffmpeg**（绝不内置）；H.264/H.265、码率预设或自定义、24/30/60 fps。转码的是**源录制**——编辑器里的缩放、标注、背景**不会**出现在该输出中
- **MV 序列** —— 基于 Media Foundation source reader 实现裁剪 / 变速 / 拼接重编码，全程不用 ffmpeg。目前由 Rust 测试套件覆盖，尚未在界面中开放

> GIF、贴纸与区域选择无需任何外部工具。只有 MP4 转码会查找 ffmpeg。

### ⏺ 录制控制
- 开始 / **暂停 / 恢复** / 停止 —— 暂停时计时器正确冻结
- **全局热键**：`Alt+R` 开始/停止、`Alt+P` 暂停/恢复 —— 应用在后台也生效
- **自动停止**：按时长上限或文件大小上限
- 保存不卡界面：大文件 MP4 封装在后台完成，UI 永不假死

### 🗂 历史与设置
- **最近录制**列表，带文件大小和日期 —— 一键在资源管理器中打开，或一键进入编辑器
- 全部设置持久化为 JSON，启动自动恢复

## 📦 安装与构建

### 环境要求
- Windows 10 1903+（Windows.Graphics.Capture API）
- [Rust](https://rustup.rs)（推荐 MSVC 工具链）与 Node.js 18+
- WebView2（Windows 11 已内置）

```bash
# 安装前端依赖
npm install

# 构建发布版二进制
npm run tauri build

# 或开发模式运行（热重载）
npm run tauri dev
```

产物位于 `src-tauri/target/release/screen-recorder.exe`。

> **GNU 工具链注意**：`windres` 需要可用的 C 预处理器 —— 请将 `mingw64/bin` 加入 PATH，或改用 MSVC 构建。

## 🚀 使用

1. 启动 `screen-recorder.exe` —— 屏幕右下角出现悬浮工具栏，主窗口提供完整设置。
2. 选择来源和画质，按 **Alt+R** 或 ● 按钮开始录制。
3. **Alt+P** 暂停/恢复，再按 **Alt+R**（或 ■）停止并保存。

默认输出：`视频\ScreenRecord\recording_YYYYMMDD_HHMMSS.mp4`

开启光标采样后，录制文件旁会写出光标轨迹副文件 `<recording>.mp4.mouse.json`。

### 剪辑与导出

1. 在「最近」列表里点某条录制的**编辑**，进入编辑器。
2. 分割、删除、排序片段；添加缩放、裁切画面、加入标注、选择背景 —— 预览实时更新。
3. 打开**导出**标签页，选择目标：
   - **GIF** —— 整条时间轴，帧率自选
   - **贴纸（PNG）** —— 播放头所在的单帧
   - **转码为 MP4** —— 源录制经 ffmpeg 重编码，可选画质档位与帧率
4. 编辑自动保存为 `<recording>.srec.json`；导出产物与录制同目录，命名为 `*-anim.gif`、`*-sticker.png`、`*-transcoded.mp4`。

### 画质档位（1080p/30fps 码率参考）

| 档位 | ~码率 | 说明 |
|------|-------|------|
| 低   | ~6 Mbps  | 文件最小 |
| 中   | ~13 Mbps | 均衡 |
| 高   | ~25 Mbps | 推荐，UI 内容近乎无损 |
| 蓝光级 | ~55 Mbps | 最高画质 |
| 自定义 | 用户设定 | 完全控制 |

> H.265 达到与 H.264 相同观感只需约 65% 的码率。

## 🏗 架构

```
┌──────────────────────────── Tauri 2 (Rust) ───────────────────────────┐
│                                                                       │
│  WGC 捕获 ──► D3D11 纹理 ──► MF SinkWriter ──► MP4 (H.264/265)        │
│       │                                   ▲                           │
│  WASAPI loopback ──► AAC 编码器 ──────────┘                           │
│  WASAPI 麦克风 ───────────────────────────┘                           │
│  光标采样 ──► <recording>.mp4.mouse.json                              │
│                                                                       │
│  React + antd 界面（主窗口 · 悬浮工具栏 · 区域选择器）                  │
│    └── Tauri IPC 命令 / 事件（进度、已保存、编码器降级）                │
│                                                                       │
│  编辑器画布（WebView）──► GIF 编码器 · PNG 贴纸                        │
│  PATH 上的 ffmpeg ──► 转码 MP4                                        │
│  MF source reader ──► MV 序列                                         │
└───────────────────────────────────────────────────────────────────────┘
```

画布是唯一的合成器：编辑器预览与 GIF/贴纸导出调用同一个 `drawFrame`，所见即所得。MP4 转码与 MV 序列则刻意绕开它 —— 它们只处理原始画面，因此其输出不含缩放与标注。

| 模块 | 路径 | 职责 |
|------|------|------|
| 捕获 | `src-tauri/src/capture/` | WGC 帧池、显示器/窗口枚举、区域截图 |
| 编码 | `src-tauri/src/encoder/` | MF SinkWriter 封装、编码器协商 |
| 音频 | `src-tauri/src/audio/` | WASAPI loopback + 麦克风采集、设备枚举、混音 |
| 输入 | `src-tauri/src/input/` | 光标/点击采样、副文件读写 |
| 录制 | `src-tauri/src/recorder.rs` | 状态机（录制/暂停/停止）、多线程 |
| 导出 | `src-tauri/src/export/` | GIF 编码器、PNG 贴纸、ffmpeg 探测/转码、MF 序列 |
| 编辑器 | `src/lib/editor/`、`src/lib/timeline/` | 工程模型、时间轴操作、画布合成器 |
| 界面 | `src/` | React 19 + antd + Tailwind 4 |
